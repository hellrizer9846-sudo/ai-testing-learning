markdown   减价# AI测试学习项目

## 项目简介
9年功能测试经验转型AI测试工程师的学习记录。
基于通义千问API，系统性地实践LLM测试、RAG测试、数据质量测试和模型评估。

## 项目结构

| 文件 | 说明 |
| ---- | ---- |
| test.py | 基础Prompt批量测试 |
| test_hallucination.py | 幻觉检测测试 |
| test_scorer.py | LLM-as-Judge评分器 |
| generate_report.py | 自动生成HTML测试报告 |
| test_rag.py | RAG系统基础测试 |
| test_rag_eval.py | RAG三维度自动评估（忠实度/相关性/完整性） |
| test_data_quality.py | 训练数据质量检查 |
| test_metrics.py | 模型评估指标计算（准确率/精确率/召回率/F1） |
| test_plan.md | HR请假助手完整测试方案文档 |

## 主要测试发现

### LLM基础测试
- 模型在需要区间逻辑推断时容易失败（入职2年年假查询，无法从"满1年5天、满3年10天"推断出答案）
- 拒绝回答时表述不够明确，只说"未规定"而不说"知识库中未包含此内容"

### 性能测试
- 短Prompt平均响应时间约1-2秒，长Prompt平均响应时间超过10秒，差距明显
- 成功率100%，稳定性良好（标准差约1.4秒）
- 建议生产环境对长Prompt场景增加loading提示

### Agent测试
- Agent工具选择准确率高，能正确判断何时调用工具、何时直接回答
- 发现工具调用参数格式不匹配问题：Agent传入JSON格式参数，但工具函数期望字符串格式，导致天气查询失败
- 建议统一工具接口的参数规范

### RAG测试
- 忠实度表现良好，平均4分以上，未发现明显编造
- 完整性评分偏低，拒绝回答时表述方式影响完整性得分
